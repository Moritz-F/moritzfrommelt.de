3Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt, einen Dienst der GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA.

Beim Aufruf der Website verarbeitet GitHub automatisch technische Daten, die Ihr Browser übermittelt. Die Verarbeitung erfolgt, um die Website technisch bereitzustellen und ihre Sicherheit zu gewährleisten.
